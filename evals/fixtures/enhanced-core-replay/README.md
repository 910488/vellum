# Enhanced core replay fixtures

De-identified Grok update-system and Omen MCPTox cases plus shared
counterexamples. These drive parser / state / decision replay. They do
**not** prove that a live model improves after a notice.

All cases are labeled **案例衍生重現**: original workspaces were already
dirty, and some error envelopes (truncated-SSE 502) are synthesized from
the protocol source of truth rather than copied from a raw HTTP capture.

Baseline core: `enhancedCodexCommit` `6576e4fb712f27bd963b6a6b559d0ba77df7cbed`.
Custom tool `input` is already handled there and is not recorded as a new
core fix.
