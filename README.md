## Make room for more work.

When a Plus account no longer covers your development workload, Vellum brings supported third-party models into Codex. Choose according to your budget and task, while keeping familiar projects, tools, and approvals.

Third-party services use their own billing and limits; your Plus allowance stays the same.

## Your models. One place.

Connect providers, choose the models available in Codex, and see account allowances at a glance. Official OpenAI requests retain their native protocol.

![Vellum Models: connected accounts and their remaining allowances](docs/images/models.png)

## Disconnect. Let the work continue.

Remote Manager separates your desktop connection from remote execution. Detach when you leave; reconnect to the same Codex session when you return.

The remote Codex daemon keeps tasks running while the host and services remain online. Vellum manages deployment, model configuration, and host readiness.

![Vellum Remote Manager: a host running detached and its paired accounts](docs/images/remote.png)

## Built around the way you work.

- **Native subagents.** Configure the default model and reasoning effort for delegated work, and follow its progress.
- **Enhanced Codex Core.** Third-party Desktop tasks gain tool-call safeguards, context recovery, and bounded continuation. Official tasks retain the unmodified Codex core.
- **Usage visibility.** Inspect context pressure, token totals, and request history.

## Get started

[Download the latest release](../../releases/latest) for Windows x64 or macOS Apple silicon. A compatible Codex installation is required; Remote Manager also requires a Linux SSH host with Docker and a systemd user session.

See [build and setup instructions](BUILDING.md) for requirements, or the [documentation index](docs/README.md) for configuration and technical details.
